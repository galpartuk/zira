# זירה — היסטוריה וסטטיסטיקה (פרויקט ג') — מסמך עיצוב

תאריך: 2026-11-16
סטטוס: אושר בצ'אט

## מה זה

תיעוד אישי לשחקן, לא ניהול דקים: אחרי טורניר השחקן רושם איזה דק הוא שיחק ואיזה דק כל יריב
שיחק, ובמסך נפרד רואה איך הלך לו עם כל דק ומול כל דק.

## החלטות

| נושא | החלטה |
|---|---|
| הדק שלי | תווית טקסט חופשי אחת **לכל טורניר** (לא רשימת קלפים) |
| דק היריב | תווית טקסט חופשי **לכל סיבוב** |
| מתי ממלאים | **רק בהיסטוריה**. מסך הטורניר נשאר נקי |
| עקביות שמות | השלמה אוטומטית מכל השמות שהשחקן כבר השתמש בהם (הדק שלו + דקי יריבים), גם בשדה הדק שלו וגם בשדות היריבים. לא כופה — מציע |
| קיבוץ בסטטיסטיקה | בלי תלות באותיות גדולות/קטנות ורווחים בקצוות; התצוגה לפי הכתיב הנפוץ ביותר |
| הוסט שמשחק | מקבל היסטוריה על הטורנירים ששיחק בהם, כמו כל שחקן |
| הערות / רשימות דקים | מחוץ לתחום |

## מסכים

**היסטוריית טורניר** (נפתח מ"היסטוריה" במסך הבית, וגם מטורניר גמור שאירחתי ושיחקתי בו):
- למעלה: "איזה דק שיחקת?" — שדה אחד עם השלמה אוטומטית.
- רשימת הסיבובים שלי: סיבוב · יריב · התוצאה מהצד שלי ("ניצחת 2–1" / BYE), ולידה שדה "הדק של היריב"
  עם השלמה אוטומטית. BYE בלי שדה.
- שמירה אוטומטית (בלי כפתור שמור).

**סטטיסטיקה** (לשונית שלישית בתחתית, ליד "טורנירים" ו"כלי משחק"):
- **הדקים שלי:** לכל דק — טורנירים, משחקים, נ/ה/ת, אחוז ניצחון.
- **מאצ'אפים:** בחירת דק שלי (או "כל הדקים") → טבלה לפי דק יריב: נ/ה/ת, אחוז ניצחון.
- משחקים בלי דק יריב מסומן נספרים תחת "לא סומן".
- BYE לא נספר במאצ'אפים ולא באחוזים.
- מצב ריק: הסבר קצר איך ממלאים (היסטוריה → טורניר).

## נתונים

```
users/{uid}/history/{tid}      רק המשתמש קורא/כותב
  name, finishedAt (ms), myDeck: string
  opp: { matchId: string }     דק יריב לכל משחק
```
- התוצאות לא נשמרות כאן — הן כבר בטורניר (`tournaments/{tid}.data`, שהשחקן רשאי לקרוא).
- הסטטיסטיקה מחושבת בטלפון: היסטוריות + מסמכי הטורנירים שלהן.
- לוגיקה טהורה (קיבוץ שמות, ספירת נ/ה/ת לפי דק ומאצ'אפ) ב-`lib/engine/stats.dart`, עם בדיקות.

## אבטחה

`match /users/{uid}/history/{tid} { allow read, write: if signedIn() && me() == uid; }` + בדיקות אמולטור.

## בדיקות

- מנוע: קיבוץ שמות, נ/ה/ת לפי דק, מאצ'אפים, BYE, "לא סומן", תיקו.
- ענן: שמירה/טעינה של היסטוריה עם fake_cloud_firestore.
- UI: השלמה אוטומטית מציעה שמות קיימים; מסך סטטיסטיקה מציג טבלאות; עברית בלי גלישה.
- כללים: רק הבעלים קורא/כותב.
